Tổng Quan Đề Tài

Xây dựng ứng dụng Web quản lý đặt phòng khách sạn bằng ASP.NET Core 10 MVC, hỗ trợ quy trình nghiệp vụ từ quản lý dữ liệu nền, tiếp nhận giao dịch, xử lý trạng thái đến Dashboard và thống kê.

🔴

Admin

Quản lý tài khoản, loại phòng, phòng và dữ liệu dùng chung.

🟡

Lễ Tân (Nhân Viên)

Quản lý phòng, khách hàng, đặt phòng, nhận/trả phòng, Dashboard, thống kê.

🟢

Khách Hàng

Đăng nhập, quản lý thông tin cá nhân, tìm & đặt phòng, theo dõi đặt phòng.

Luồng Nghiệp Vụ — Người Dùng

Đăng nhập→ Tìm phòng→ Kiểm tra ngày→ Đặt phòng→ Xác nhận→ Nhận phòng→ Trả phòng→ Tính tiền

Luồng Trạng Thái Giao Dịch

Chờ xử lý→ Đang xử lý→ Hoàn thành
↳ Có thể Hủy / Từ chối (khi thỏa mãn điều kiện)

Format Commit Message

// Format:
[Mã SV] [Module] Nội dung công việc

Ví dụ theo từng Module

[22103100001] [TaiKhoan] Tao Entity TaiKhoan va Data Annotation
[22103100002] [Phong] Them chuc nang phan trang voi Skip Take
[22103100003] [DatPhong] Kiem tra trung lich dat phong bang LINQ
[22103100004] [TiepNhan] Xu ly trang thai nhan phong va tra phong
[22103100005] [ThongKe] Them Dashboard tong quan voi LINQ
⚠️
Commit message phải viết KHÔNG DẤU để tránh lỗi encoding. Mỗi thành viên phải có nhiều commit phù hợp tiến độ, KHÔNG dồn toàn bộ vào 1 commit cuối!

Comment Header Mã Nguồn

// Họ và tên: Nguyễn Văn A // Mã sinh viên: 22103100001 // Nội dung thực hiện: Quản lý tài khoản, đăng nhập, // phân quyền và quản lý loại phòng.
